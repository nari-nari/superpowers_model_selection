# Codex拡張の検証ケース

対象仕様: [Codex拡張検証仕様](../../docs/superpowers/specs/2026-11-11-codex-extension-validation-design.md)。結果は[検証記録](../../docs/superpowers/validation/codex-extension.md)へ保存する。fixtureによる判断と実機適用を混同しない。

| ID | 入力・操作 | 期待動作と必要証拠 |
| --- | --- | --- |
| CX01 | VS Codeの拡張画面・当該Codex会話の情報を確認 | 稼働版・エンジン版・本体ソース・契約を記録。インストールファイル版やCLI版だけではpassにしない |
| CX02 | 試験フォルダで新しい拡張会話を開始し入口とSKILLを読む | 方針2026-11-11.2、bindingと実ファイル、実際の読込履歴を照合。同名重複を識別。スキル一覧だけでは不足 |
| CX03 | 利用可能な実ID2件を正式引数または確認済みworkerで各1回指定 | 同一fixtureを読み、引数・子スレッド・独立した実効IDを照合。推論・容量の未観測値は個別unknown。本文中のモデル名だけでは不合格 |
| CX04 | 安全な拒否を最大1回再現。観測された上書き・fallback・未対応推論／contextも確認 | 拒否を成功にしない。不一致で再適格性確認し、未再現枝をunverifiedにする。架空IDを繰り返し送らない |
| CX05 | 既存S01・S02・S05・S08をfixtureと明示して判断 | 通常レビューは適格候補の完了費用を比較。高リスクで未適格を除外、縮小再レビューは再評価、未価格を最安にしない |
| CX06 | ChatGPT Plusの含有利用枠／追加クレジットの適用条件と2候補の料金根拠を確認 | 契約・speed・単位が確定した場合だけ完了経路を見積る。Copilot換算／API価格の流用なし。含有枠の計算根拠不明なら費用選択保留 |
| CX07 | CX03の各呼出し前後から観測できる使用量を採取 | 呼出し単位の使用量、または帰属が明確な差分だけ比較。集約残枠だけなら実費unknown。計測目的の再呼出しなし |
| CX08 | 既存S06と実際の本体ワークフローを比較 | 必須レビュー・独立性・修正上限を維持。判断試験だけならその範囲を明記 |
| CX09 | 所有記録に従い配置・同版更新・ドリフト検出・解除 | 既存／未所有物を保持。解除後の拡張新会話も確認して初めて実機pass |
| CX10 | 既存S07を拡張の再開／新会話で再現 | 版・選択記録を復元し、条件変更時は再選択。実際の圧縮を再現しなければ圧縮受入は未検証 |

S01等の本文は[既存判断ケース](independent-routing-scenarios.md)を使い、架空IDをネイティブ呼出しに用いない。

## 同一fixtureとCX03の依頼

`fixture.txt` の内容は次の1行（末尾LF）。

```text
routing-fixture: codex-extension-v1
```

各子へ渡す本文は同一とし、モデルと対応する設定だけを正式な経路で指定する。

```text
読み取り専用の検証です。現在の試験プロジェクトのfixture.txtを読み、1行をそのまま返してください。ファイル編集・ネットワーク・追加の子への委譲は行わないでください。
```

CX03の固定モデル試験はルーティング能力の確認であり、費用最適化ではない。初回は各モデル1回、同時1子。読み込み未確認、正式経路なし、入力が容量へ収まる根拠なしの場合は依存する試験を開始しない。

## 証拠の反例

- インストール済みpackage.jsonに版があるだけ: CX01の稼働版はunknown。
- CLIで同一fixtureを返せた: CLIの補助証拠。CX03の拡張実機はunverified。
- 子が自分のモデル名を返した: 自己申告。model_effectiveはunknown。
- 正式指定が受理されたがモデルID非公開: 経路は受理と記録し、適用受入はunverified。
- 残枠が前後で減少したが他会話も稼働: 帰属不明。actual_costはunknown。

## 参照取得試験（実機とは別）

基準コミットと変更後の資料に対し、同一評価設定 `gpt-6.1-sol / medium / fork_turns none` で次を問う。これは参照案内の取得・適用確認で、遵守率・実効モデル・料金・拡張適用を証明しない。

1. Codex拡張用の入口配置と正式指定経路の資料はどこか。
2. Codex／ChatGPT契約にCopilotのUSD/0.01換算を使えるか。料金根拠はどこか。
3. 費用選択保留と、2件の固定モデル能力試験を区別できるか。
4. runtime、費用単位、拡張由来証拠、未知値をどう記録するか。
